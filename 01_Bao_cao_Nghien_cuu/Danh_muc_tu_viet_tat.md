# DANH MỤC TỪ VIẾT TẮT

| Từ viết tắt | Thuật ngữ tiếng Anh (nếu có) | Nghĩa tiếng Việt |
|-------------|--------------------------------------------------|----------------------------------------------------|
| **AI** | Artificial Intelligence | Trí tuệ nhân tạo |
| **API** | Application Programming Interface | Giao diện lập trình ứng dụng |
| **ARM** | Advanced RISC Machine | Cấu trúc vi xử lý máy tính nhúng |
| **CLAHE** | Contrast Limited Adaptive Histogram Equalization | Cân bằng biểu đồ thích ứng giới hạn độ tương phản |
| **CPU** | Central Processing Unit | Bộ vi xử lý trung tâm |
| **CSR** | Client-Side Rendering | Kết xuất giao diện phía máy khách (trình duyệt) |
| **CSS** | Cascading Style Sheets | Ngôn ngữ định dạng trang web |
| **DOM** | Document Object Model | Mô hình đối tượng tài liệu |
| **DSS** | Decision Support System | Hệ thống hỗ trợ ra quyết định |
| **EdTech** | Educational Technology | Công nghệ giáo dục |
| **HTML** | HyperText Markup Language | Ngôn ngữ đánh dấu siêu văn bản |
| **HTTP** | Hypertext Transfer Protocol | Giao thức truyền tải siêu văn bản |
| **JSON** | JavaScript Object Notation | Định dạng trao đổi dữ liệu văn bản |
| **LLM** | Large Language Model | Mô hình ngôn ngữ lớn |
| **LMS** | Learning Management System | Hệ thống quản lý học tập |
| **NLP** | Natural Language Processing | Xử lý ngôn ngữ tự nhiên |
| **OCR** | Optical Character Recognition | Nhận dạng ký tự quang học |
| **OMR** | Optical Mark Recognition | Nhận dạng dấu quang học (chấm thi trắc nghiệm) |
| **ORM** | Object-Relational Mapping | Ánh xạ đối tượng - quan hệ (trong cơ sở dữ liệu) |
| **OS** | Operating System | Hệ điều hành |
| **PAT** | Personal Access Token | Mã thông báo truy cập cá nhân (GitHub) |
| **RAM** | Random Access Memory | Bộ nhớ truy cập ngẫu nhiên |
| **RPi** | Raspberry Pi | Máy tính nhúng cỡ nhỏ |
| **SLM** | Small Language Models | Mô hình ngôn ngữ nhỏ |
| **SQL** | Structured Query Language | Ngôn ngữ truy vấn cơ sở dữ liệu có cấu trúc |
| **SSR** | Server-Side Rendering | Kết xuất giao diện phía máy chủ |
| **UI** | User Interface | Giao diện người dùng |
| **UX** | User Experience | Trải nghiệm người dùng |
| **Wasm** | WebAssembly | Ngôn ngữ lập trình chạy trên trình duyệt |
